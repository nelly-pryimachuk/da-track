# DA Track

Веб-сайт портфоліо для відстеження прогресу у вивченні дата-аналітики: каталог навичок (SQL, Excel, Power BI) і власні кейси з повним CRUD.

## Середовище

Node.js: v24.21.0
npm: 11.19.0
Git: 2.55.0
Docker: 29.8.0, Docker Compose: v5.5.1
Основний варіант: A (Windows, стандартні інсталятори)
React Router: 8.4.0

## Запуск

Нативно: `npm install`, потім `npm run dev`.

Docker:

```
docker compose build
docker compose run --rm web npm install
docker compose up
```

Адреса Docker: http://localhost:5173.
Зупинення контейнера: `Ctrl+C`, видалення: `docker compose down`.

## Збірка і перевірка

```
npm run lint
npm run build
```

Або: `docker compose run --rm web npm run build`

## Що реалізовано

- Каталог навичок із пошуком і фільтром (дані лише для читання).
- Кейси з повним CRUD: створення, перегляд, редагування й видалення з підтвердженням, валідація форм, пошук, фільтр за навичкою та сортування (параметри в URL).
- Асинхронний шар даних: сервіс із двома адаптерами, стани завантаження й помилки з повтором, захист від повторного подання.

## Джерело даних

Застосунок працює з сервісом `caseService`, який обирає реалізацію за змінною `VITE_DATA_SOURCE`:

- `mock` (за замовчуванням): localStorage цього браузера (ключ `daTrack.cases.v1`) із затримкою 600 мс. Кейси доступні після перезавантаження сторінки в межах того самого origin (схема, хост, порт). Основний режим, перевірений вручну.
- `api`: адаптер на `fetch`, базова адреса береться з `VITE_API_BASE_URL`. Адаптер підготовлено за контрактом з `docs/component-architecture.md`, але з реальним сервером **не запускався**.

Налаштування: за потреби скопіюйте `.env.example` у `.env.local` (для mock це необов'язково). Після зміни env-файлів перезапустіть `npm run dev`. Секретів у `VITE_` змінних зберігати не можна: вони потрапляють у клієнтську збірку.

Перемикання режиму не переносить кейси між локальним сховищем і сервером. Якщо застосунок працює в Docker, адреса API має бути доступна саме браузеру, а не лише контейнеру.
