# План проєкту: DA Track

## Тема
Веб-сайт портфоліо для відстеження прогресу у вивченні дата-аналітики.

## Проблема
Прогрес самостійного навчання (курси, інструменти, практичні роботи) розпорошений між різними джерелами — немає єдиного публічного місця, яке б структуровано показувало навички та виконані кейси.

## Користувачі та сценарії
- **Відвідувач профілю** (рекрутер, колега з навчання) — переглядає каталог навичок та кейсів, щоб оцінити прогрес.
- **Авторка** — додає, редагує та видаляє записи про виконані практичні роботи.

## Сутності

- **Навичка** (довідник, лише перегляд): id, назва, категорія, статус
  ("опрацьовую теорію" / "практикую" / "починаю вивчати"), опис.
- **Кейс** (головна сутність з повним CRUD): практична робота,
  прив'язана до однієї або кількох навичок.

### Правила полів кейсу

| Поле | Правило |
|---|---|
| `id` | створюється системою, не редагується у формі |
| `skillIds` | від 1 до 4 унікальних навичок, що існують у каталозі |
| `title` | обов'язкове, від 3 до 80 символів без крайніх пробілів |
| `summary` | обов'язкове, від 20 до 500 символів без крайніх пробілів |
| `hoursSpent` | обов'язкове ціле число від 1 до 100 |
| `link` | необов'язкове; якщо вказано, має бути адресою http:// або https:// |
| `readyToPublish` | логічне; якщо `true`, то `link` обов'язкове |

Правила реалізовано однією функцією `validateCase` (`src/domain/caseValidation.js`),
яку використовують і форма, і операції колекції.

### Зберігання

Кейси живуть у пам'яті запущеного застосунку (`CasesProvider`). Після
перезавантаження сторінки відновлюються початкові записи з `src/data/cases.js`.

## Реалізовано в Л1.1
- Каталог навичок (SQL, Excel, Power BI) на головній сторінці.

## Карта маршрутів (Л3.1)

| Адреса | Сторінка | Джерело запису | Якщо запису немає |
|---|---|---|---|
| `/` | HomePage | немає | не застосовується |
| `/skills` | SkillsContainer → SkillsPage | `data/skills.js`; `?q=`, `?practicing=1` | порожній результат фільтра |
| `/skills/:skillId` | SkillDetailsPage | навичка за `skillId` | NotFoundPage |
| `/cases` | CasesPage | колекція `CasesProvider`; `?q=`, `?skill=`, `?sort=` | порожня колекція / порожній результат |
| `/cases/new` | CaseCreatePage | порожня форма; `?skillId=` лише попередньо відмічає навичку | невідомий `skillId`: NotFoundPage |
| `/cases/:caseId` | CaseDetailsPage | кейс за `caseId` | NotFoundPage |
| `/cases/:caseId/edit` | CaseEditPage | кейс за `caseId` | NotFoundPage |
| інші адреси | NotFoundPage | немає | не застосовується |

Параметри списку кейсів: `q` (пошук у назві та описі), `skill` (id навички або
всі), `sort` (`title`, `hours-asc`, `hours-desc`). Невідомі значення
трактуються як значення за замовчуванням.
